# Financial data audit (2010–2025)

All amounts are in **millions of Danish kroner (DKK)**. The analysis uses three annual fields: `receita`, `lucro_operacional`, `lucro_liquido`.

The dataset `dados/originais/lego_financas_2010_2025_conferencia.csv` contains 16 years × 3 fields = **48 numeric values**. The accompanying [`auditoria_financeira_48_valores.csv`](../auditoria_financeira_48_valores.csv) records the review of these values against the Financial Highlights tables in four official annual reports.

- [LEGO Group Annual Report 2011](https://www.lego.com/cdn/cs/aboutus/assets/bltfc5240b2ffa6738f/Annual_Report_2011_ENG.pdf) — historical 2010–2011 values.
- [LEGO Group Annual Report 2016](https://www.lego.com/cdn/cs/aboutus/assets/blt0b5f75205fb17080/Annual_Report_2016_ENG.pdf) — historical 2012–2016 values.
- [LEGO Group Annual Report 2021](https://www.lego.com/cdn/cs/aboutus/assets/blt248041929be3b572/Annual_Report_2021_ENG.pdf) — historical 2017–2020 values.
- [LEGO Group Annual Report 2025](https://www.lego.com/cdn/cs/aboutus/assets/blte543dd46714c9226/The_LEGO_Group_2025_Annual_Report.pdf) — 2021–2025 values.

**Caution:** IFRS 16 and changes in presentation can affect cross-year comparison of some financial measures. The verification is an educational source-consistency check, not an external financial audit.
